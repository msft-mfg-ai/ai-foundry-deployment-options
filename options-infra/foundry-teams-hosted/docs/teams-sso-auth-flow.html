Why Toolbox cannot just use it

The bearer token stops at the hosted bot.

The Toolbox request currently receives a Foundry call ID and trusted user identity context. It does not receive the Bot Service token. An object ID says who; it does not grant permission to act at Graph or a custom MCP API.
